# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

Next.js, React, Tailwind CSS, Electron, and Vite.

## Users

Creators, freelancers, agencies, and developers who want a free, unrestricted, open-source AI image, video, and lip sync studio without content filters or subscription fees.

## Product Purpose

To provide an unrestricted open-source alternative to closed AI video platforms, allowing users to generate high-quality AI media (images, videos, lip sync, workflows) using 400+ state-of-the-art models either locally or via API.

## Positioning

An open-source, self-hostable, and white-labelable AI studio with absolutely no content filters or platform guardrails, supporting both bundled local inference (sd.cpp) and remote inference.

## Operating Context

Users interact with the studio either via a desktop app (macOS, Windows, Linux) or a hosted web version. Workflows involve writing text prompts, uploading reference images, chaining multi-step AI pipelines, and generating assets locally or via API.

## Capabilities and Constraints

- Dual mode generation: Text-to-Image/Video and Image-to-Video/Image.
- Multi-image inputs (up to 14 reference images).
- Local inference requires Metal (Mac) or CUDA/Vulkan/ROCm.
- Monorepo architecture with `packages/studio` for shared components.
- API keys are stored only in local browser storage.

## Brand Commitments

- "No filters" — full creative freedom.
- "Free & open-source" — no vendor lock-in.

## Evidence on Hand

- Hosted version at Local API.ai/open-generative-ai.
- Desktop binaries available for macOS, Windows, and Linux.
- Extensive catalog of 400+ models across 8 categories.
