# User Guide

Welcome to DevineDesk! This guide covers the basics of using the platform.

## Getting Started
1. **Sign Up:** Navigate to `/auth/register` to create an account.
2. **Dashboard:** Upon login, you'll land on your personal dashboard (`/dashboard`), summarizing your credit usage and recent generations.

## AI Generative Workflows
DevineDesk allows you to build AI pipelines using a visual node-editor.
- Navigate to the **Studio** to access the visual builder.
- Drag and drop nodes (e.g., LLM prompts, Image generation, API webhooks).
- Connect nodes to form a continuous data flow.
- Click **Run** to execute the pipeline in the background.

## Billing & Credits
- DevineDesk operates on a usage-based credit system.
- View your remaining balance in the top navigation bar.
- Purchase more credits or upgrade to a monthly subscription via the **Billing** tab.

## Workspaces and Teams
- You can create shared **Workspaces** to collaborate with your team.
- Switch between personal and team workspaces using the context switcher in the sidebar.
- Invite members and assign roles (Admin, Member, Viewer) via the Workspace Settings.

## API Keys
- For programmatic access, generate an API Key in **Developer Settings**.
- Keep your keys secure; they are only displayed once!
