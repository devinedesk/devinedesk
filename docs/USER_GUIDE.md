# DevineDesk User Guide

Welcome to DevineDesk! 

## Getting Started
1. **Sign Up**: Create an account or log in via Google/GitHub.
2. **Dashboard**: Your main hub for all recent activity.
3. **Workspace**: Create a workspace to collaborate with your team.

## Generating Assets
- Navigate to the **Studio** tab to generate images, videos, and lip-sync media.
- Use the **Settings** panel within the Studio to choose your AI model.

## Billing
- Check your token usage and subscription status in **Settings > Billing**.

## Support
- If you encounter any issues, create a support ticket in **Settings > Support**.
